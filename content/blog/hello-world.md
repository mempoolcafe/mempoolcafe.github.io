## how to write a post

1. add a new file to `content/blog/`, e.g. `content/blog/my-first-thought.md`
2. start it with a frontmatter block (`title`, `date`, `summary`, and optionally `topic`)
3. write the rest in regular Markdown
4. commit and deploy

the filename becomes the link, so `my-first-thought.md` lives at `/blog/my-first-thought`.

## topics

tag a post with one of the topics from `lib/portfolio-data.ts`, like `topic: tech` or `topic: blockchain`. it then shows up when someone picks that topic in the filter dropdown. this post has no topic, so it only shows under "all topics".

> posts from the last 30 days get a blinking **NEW!** tag automatically.
